# Gather

Gather is a touch-friendly recipe companion designed for a kitchen screen or any modern browser. It is a lightweight, dependency-free static web app.

## Run it

Open `index.html` in a modern browser. No build step or server is required.

## Features

- Search recipes and filter by category.
- Save favorite recipes; saved choices stay in the browser.
- Open a recipe for ingredients and step-by-step instructions.
- Adjust ingredient quantities by changing the serving count.
- Responsive layout and keyboard shortcut (`/`) to jump to search.
